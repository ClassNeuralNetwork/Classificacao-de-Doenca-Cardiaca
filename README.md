# Classificação de Doença Cardíaca

Projeto de classificação de doenças cardíacas utilizando uma **Rede Neural Artificial** e **SHAP** para análise da importância das características.

## Tecnologias

- Python
- TensorFlow / Keras
- Scikit-learn
- SHAP
- Pandas
- Matplotlib

## Modelo

A rede neural utiliza camadas Dense, ReLU, Dropout e uma saída com função Sigmoid para classificação binária.

## Resultados

- Acurácia: **91,30%**
- Precisão: **92,16%**
- Recall: **92,16%**
- F1-Score: **92,16%**

## Dataset

**Heart Failure Prediction Dataset**  
Fonte: Kaggle — fedesoriano
